# Правила работы

- Выполнять лабораторные по требованиям из `tasks.md`.
- Перед изменениями читать соответствующий код и инструкции; выбирать простое решение без лишних зависимостей.
- Писать самодокументирующийся код с понятными именами; не добавлять комментарии в код.
- Использовать Java из `mise.toml`; для сборки, запуска и проверок использовать задачи `mise run`, для разовых команд — `mise exec -- <команда>`.
- Проверять изменённое поведение перед коммитом.
- Делать атомарные Git-коммиты: один коммит — одно законченное логическое изменение. Не смешивать несвязанные задачи.
- Завершать каждое проверенное логическое изменение командой `git commit` с понятным сообщением.
- Работать в отдельных ветках и создавать pull request в `main`; не вливать изменения без запроса пользователя.
- Не переписывать историю и не выполнять force-push без явного разрешения пользователя.
- Не использовать субагентов без явного запроса пользователя для текущей задачи.
